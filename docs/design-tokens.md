# Design Tokens

The reader combines an academic publication with modern technical documentation.

| Token | Value | Purpose |
| --- | --- | --- |
| `--ink` | `#0d1425` | primary text |
| `--muted` | `#657085` | supporting text |
| `--paper` | `#f7f9fc` | warm reading background |
| `--card` | `#ffffff` | raised content |
| `--navy` | `#020b1c` | navigation and hero |
| `--teal` | `#16c8bb` | progress and learning |
| `--blue` | `#4f7df3` | concepts and links |
| `--violet` | `#7656ea` | research and papers |
| `--amber` | `#e4a10c` | exercises |
| `--coral` | `#ff5f45` | primary actions |
| `--danger` | `#c62828` | errors only |

Long-form prose targets 65-80 characters per line, a minimum 1.65 line height and a humanist or serif reading face. Interface text uses Geist; code uses a monospace face. Motion is restrained and disabled under `prefers-reduced-motion`.
