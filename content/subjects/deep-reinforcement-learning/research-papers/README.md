# Research-paper reading path

The 30-resource Subject Lead plan separates foundational, established, modern,
survey/tutorial, and applied readings. Chapter 1 starts with Sutton and Barto,
Watkins and Dayan, Mnih et al., Henderson et al., and Gymnasium. Each paper
note will be added only after DOI/arXiv identity, venue, and URL verification;
the brochure does not contain an official reading list.
