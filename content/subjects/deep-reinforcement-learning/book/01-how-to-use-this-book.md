# How to use this book

Read each chapter in three passes. First follow the running problem and write
down what the agent can observe, do, and optimise. Next derive the update with
symbols defined in plain language. Finally run the smallest test before
changing the environment or model size.

Every code listing states its Python assumptions and separates first-principles
logic from library conveniences. Record the seed, package versions, environment
version, evaluation policy, and number of environment steps for every result.
When a chapter calls something supplementary or an advanced extension, it is
useful teaching depth—not a claim about an unprovided official unit list.
