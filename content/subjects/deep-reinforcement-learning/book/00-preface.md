# Preface

Deep reinforcement learning is easy to describe and hard to measure. An agent
receives observations, chooses actions, and receives rewards, but a useful
agent must cope with delayed consequences, correlated experience, changing
data distributions, and potentially unsafe exploration. This book treats those
properties as the subject rather than as implementation details.

The official brochure verifies the subject title and Semester 2 placement only.
The chapter sequence is an educational interpretation and is labelled in the
metadata and plans. Readers should bring the prerequisite knowledge listed in
the next pages, and should treat each experiment as a claim with an evidence
contract rather than as a leaderboard exercise.

The examples use small, reproducible environments before neural agents. That
order is deliberate: a neural network cannot repair a wrong reward, a leaking
terminal transition, or an incorrectly measured return.
