# Assignments

Build the sandboxed five-question document agent from Chapter 1. Submit code,
fixtures, tests, dependency lockfile, a threat model, trace samples, cost and
latency measurements, a comparison of one-shot/ReAct/Plan-and-Execute, and a
limitations report. Include at least one malformed tool response, one prompt
injection fixture, one missing-source refusal, and one budget-exhaustion trace.
