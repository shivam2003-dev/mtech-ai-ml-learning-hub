# Preface

An agent is not merely a chat completion with a longer prompt. It is a system
that observes a task, chooses actions, receives results, and decides whether
the result is good enough to stop. That loop can make software useful, but it
also turns ambiguous language into operational consequences. This book treats
the loop as an engineered control system: every tool has a contract, every
memory has a retention policy, and every answer has an evidence boundary.

The official course description is available, but the brochure does not
prescribe assessment details. Topics marked **Prerequisite**, **Supplementary**,
**Advanced extension**, or **Industry application** are therefore labelled
plainly rather than presented as university requirements.
