# Paper reading path

The curated path has foundational agent loops (ReAct, Toolformer), feedback and
planning (Reflexion, Plan-and-Solve), memory and embodiment (Generative Agents,
Voyager), grounding (RAG), and governance (NIST AI RMF and its Generative AI
Profile). For each paper, record the problem, controller, tools, evaluation,
limitations, and reproduction resources. Do not treat benchmark success as a
production safety guarantee.
