# Datasets and workloads

- **Synthetic tabular fixtures:** generated with a published seed; suitable for
  validation without personal data.
- **OpenAPI examples:** the official OpenAPI specification examples; preserve
  the specification licence and version.
- **HTTP load traces:** generate locally from a declared distribution; do not
  replay real user identifiers.
- **Public ML datasets:** select only after checking licence, provenance,
  sensitive attributes, and whether redistribution is allowed.

Every project must record source URL, version/date, licence, checksum where
possible, transformation, and deletion/retention policy.
