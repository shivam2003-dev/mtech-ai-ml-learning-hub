# Assessment design

The proposed assessment is a portfolio, not an official university weighting:

- 20% contract and threat model;
- 20% tested local implementation;
- 20% reliability experiment;
- 20% deployment and observability evidence; and
- 20% technical report and oral defence.

Every score must be tied to an artefact, a reproducible command, and a stated
limitation. Never award points for a dashboard screenshot without the query,
time window, and data-quality caveat that produced it.
