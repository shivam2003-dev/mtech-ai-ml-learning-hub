# Preface

An API is not merely a URL around a function. It is a promise between a caller,
an implementation, and an operating environment. This book studies that promise
through an AI/ML lens: models need data contracts, predictable latency, safe
failure modes, and evidence that a prediction is fit for use.

Because the official brochure names this elective without units, every proposed
topic is marked as supplementary or an advanced extension. Read the chapters as
a coherent reference path, not as a claim about university assessment.
