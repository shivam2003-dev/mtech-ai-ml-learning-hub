# Prerequisites

- **Prerequisite:** Python functions, exceptions, typing, virtual environments,
  JSON, HTTP verbs/status codes, and Git.
- **Prerequisite:** basic probability, model evaluation, and data leakage.
- **Supplementary:** Linux processes, DNS, TLS, SQL, and container images.
- **Advanced extension:** Kubernetes scheduling, service meshes, distributed
  tracing, and cloud IAM.

If HTTP is unfamiliar, first build a tiny request/response program and inspect
headers with a local client. If ML is unfamiliar, complete the introductory
Machine Learning and Statistical Methods books before serving predictions.
