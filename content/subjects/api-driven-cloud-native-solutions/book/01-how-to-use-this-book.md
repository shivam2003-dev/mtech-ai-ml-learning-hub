# How to use this book

Read the narrative chapters in order, but run the lab after each one. Start with
the smallest local service, write its contract, test its failure behaviour, and
only then add a database, model, container, or cloud deployment. Keep a decision
log: assumption, evidence, trade-off, and follow-up experiment.

The chapter prose uses MathJax for useful equations and small Python examples
for reproducible reasoning. Code blocks are educational; credentials, production
data, and autonomous actions never belong in a tutorial repository.
