# API-Driven Cloud-Native Solutions

> **Curriculum status:** The official brochure verifies this elective title and
> its placement in the configurable Semester 2–3 pool. It does not publish
> units, outcomes, prerequisites, tools, or chapter ordering for this subject.
> The sequence below is therefore a proposed educational interpretation. Each
> addition is labelled **Prerequisite**, **Supplementary**, **Advanced extension**,
> or **Industry application**, and must not be mistaken for an official unit.

## Reference chapter

1. [From an API Contract to a Cloud-Native Service](./chapters/01-from-an-api-contract-to-a-cloud-native-service/) — a supplementary first chapter with a tested FastAPI example and explicit production boundaries.

## Proposed book sequence

1. From an API Contract to a Cloud-Native Service
2. HTTP Semantics, Versioning, and OpenAPI Contracts
3. Typed Validation, Errors, and Idempotent Workflows
4. Packaging a Service with Containers
5. Configuration, Secrets, and Data Boundaries
6. Reliability: Timeouts, Retries, Queues, and Backpressure
7. Observability, SLOs, and Incident Evidence
8. Deployment Topologies, Rollouts, and Autoscaling
9. Securing ML and Data APIs
10. Capstone: Operating an Intelligent Cloud-Native Product

Only Chapter 1 is authored in this vertical slice. Future chapters remain
planned until their source, mathematics, code, editorial, rendering, and
accessibility reviews pass.
