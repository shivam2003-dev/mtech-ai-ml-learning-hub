# Assignments

1. Write an OpenAPI contract for a model prediction endpoint, including error
   examples and a compatibility policy.
2. Build a failure matrix for timeouts, malformed input, stale model, queue
   saturation, dependency failure, and operator rollback.
3. Measure p50, p95, and p99 latency under a fixed load; explain why the mean is
   insufficient for a user-facing SLO.
4. Review a container image for secret leakage, excessive privileges, mutable
   tags, and missing health checks.
5. Conduct a privacy and threat-model review for a feature API that handles
   personal data.

Submit code, commands, results, assumptions, and a short limitations section.
