# Glossary

- **API contract:** The externally observable request, response, error, and
  compatibility promise of a service.
- **Cloud-native:** A design approach using automation, immutable artefacts,
  observable services, and elastic infrastructure; it is not synonymous with
  “put it in a container.”
- **Idempotency:** Repeating an operation has the same intended effect as
  performing it once.
- **SLO:** A target for a service-level indicator over a stated window.
- **Readiness:** Evidence that a running instance can receive traffic safely.
- **Model endpoint:** An API boundary that invokes a trained model or a model
  retrieval workflow.
- **Backpressure:** A mechanism that prevents producers from overwhelming a
  downstream component.
