# Quiz bank

1. Why is an OpenAPI schema a compatibility boundary rather than only generated
   documentation?
2. What distinguishes liveness from readiness?
3. Why can retrying a POST duplicate a business action?
4. Which latency percentile would expose a tail-risk regression better than a
   mean, and what workload context must accompany it?
5. Name two reasons a container does not by itself make a system cloud-native.

Answers should name the contract, safety, and evidence behind each response.
