# Glossary

This glossary currently covers only the reference chapter.

- **Assumption:** a condition accepted for a claim or derivation; it must be stated when it affects validity.
- **Codomain:** the declared target set of a function.
- **Counterexample:** one valid case that makes a universal statement false.
- **Dimension:** contextual term for the number of coordinates in a vector space or the length of a specific axis; state which meaning is intended.
- **Domain:** the set of permitted inputs to a function.
- **Function:** a mapping that assigns each input in its domain exactly one output in its codomain.
- **Index:** a label selecting an element or coordinate.
- **Matrix:** a two-index rectangular array of scalars, commonly used to represent a linear map after bases are chosen.
- **Relation:** a set of ordered tuples that records which objects are related.
- **Scalar:** a single element of a number field, usually \(\mathbb{R}\) in this chapter.
- **Set:** an unordered collection defined by membership.
- **Shape:** the ordered tuple of axis lengths of an array.
- **Tensor:** a mathematical multilinear object; in software, the word often means a multidimensional homogeneous array. These meanings are related but not identical.
- **Vector:** an element of a vector space; coordinates depend on a chosen basis.
