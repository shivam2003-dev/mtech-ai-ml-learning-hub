# Further Reading

For the reference chapter:

- Deisenroth, Faisal, and Ong, *Mathematics for Machine Learning*, especially the introduction and linear algebra chapter.
- Strang, MIT 18.06SC, for the transition from matrix notation to linear transformations and systems.
- Harris et al. (2020), “Array programming with NumPy,” for the role of array programming in scientific computation.
- NumPy’s official `ndarray` and broadcasting documentation for implementation semantics.

This is a short, verified list rather than an exhaustive catalogue. Probability readings are intentionally excluded from this reference-chapter scope.
