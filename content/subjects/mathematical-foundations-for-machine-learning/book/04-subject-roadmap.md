# Subject Roadmap

The planning bundle proposes this dependency sequence:

```text
mathematical language
  -> vectors, matrices, and linear systems
  -> geometry and least squares
  -> matrix factorizations
  -> vector calculus
  -> optimization
  -> numerical stability
```

Only **Mathematical Language for Machine Learning** has been drafted as the reference chapter. The remaining subjects are planned, not published. Probability content is omitted from this reference slice pending coordinated scope ownership with Introduction to Statistical Methods.
