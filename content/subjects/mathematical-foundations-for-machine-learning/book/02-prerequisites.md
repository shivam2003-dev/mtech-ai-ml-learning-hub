# Prerequisites

These are educational prerequisites, not official university prerequisites:

- secondary-school algebra, including rearranging equations and reading summations;
- basic functions, graphs, domains, and ranges;
- basic Python functions, conditionals, loops, and exceptions;
- willingness to state assumptions and check dimensions.

The reference chapter refreshes set notation, logic, function notation, indexing, and array shapes. It does not assume probability and does not teach probability.
