# Learning Outcomes

The proposed, non-official outcomes for the reference slice are:

- distinguish mathematical objects from their notation and software representations;
- define sets, relations, and functions with domains and codomains;
- read universal and existential statements without reversing their logic;
- explain scalar, vector, matrix, and tensor shapes;
- expand indexed expressions and verify compatible dimensions;
- translate an affine batch computation into tested NumPy;
- refute an invalid universal claim with one valid counterexample;
- document assumptions, edge cases, complexity, and limitations.
