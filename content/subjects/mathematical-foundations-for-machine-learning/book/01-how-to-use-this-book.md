# How to Use This Book

Read with paper, a notation ledger, and a Python environment. For each expression:

1. list every symbol and its meaning;
2. record its type, domain, and shape;
3. state the operation being applied;
4. verify that the input and output shapes agree;
5. test a small numerical example;
6. construct an edge case or counterexample.

Code is evidence about an implementation, not a proof of a universal claim. A derivation explains why an expression follows under stated assumptions; tests show that selected cases behave as expected. Use both.
