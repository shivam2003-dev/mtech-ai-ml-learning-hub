# AI and ML Techniques for Cyber Security

> **Curriculum status:** the official brochure identifies this as a named
> elective with a course-topic description, but does not assign it to one
> specific semester. The twelve-chapter sequence below is an educational
> interpretation of the twelve topic phrases; it is not an invented official
> unit list. Prerequisites, workload, tools, and assessments are labelled
> educational design.

The official description names: AI and ML in cybersecurity; cybersecurity
fundamentals; gradient-boosting vulnerability management; graph-based static
analysis; graph neural networks for malware, attack paths, and code
vulnerabilities; supervised and deep-learning malware detection; NLP and
Transformers for phishing and email; deep-learning traffic analysis;
autoencoder-based user and entity anomaly detection; adversarial ML;
generative AI and LLMs in security operations; and reinforcement-learning
response. Chapters are released only after each chapter's separate evidence and
code gates pass.

## Published reference chapter

1. [From a Security Question to an ML Evidence Contract](./chapters/01-from-security-question-to-ml-evidence-contract/) — **Official topic: Introduction to AI and ML in Cybersecurity**, with labelled prerequisite, supplementary, and industry-application depth.

10. Adversarial Machine Learning and Robust Defence
