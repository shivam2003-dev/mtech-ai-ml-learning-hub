# How to use this book

Begin each chapter with the security question and write down the protected
asset, observation window, decision owner, allowed action, and unacceptable
failure. Reproduce the small numerical example by hand before running code.
Keep a claim ledger: mark whether a sentence is a definition, a paper result,
an engineering recommendation, or an original educational explanation.

Use public, consented, or synthetic data in labs. Never execute a suspicious
sample merely because a tutorial mentions malware. For paper reading, identify
the threat model, data collection process, split chronology, baseline,
operational cost, and limits before comparing percentages.
