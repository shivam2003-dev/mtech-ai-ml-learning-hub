# Preface

Security is an adversarial, socio-technical setting. A detector is not a
classifier floating above the network: it is a component in a process with
assets, people, permissions, response costs, and an opponent who can change
the data. This book keeps the security question in view while showing the
mathematics and engineering of machine learning.

The brochure supplies twelve topic phrases, not a prescribed book, chapter
order, or examination rubric. Every chapter therefore marks official coverage
and labels prerequisite, supplementary, advanced-extension, and
industry-application material. No chapter should be read as permission to run
malware, scan systems without authorization, or automate destructive response.
