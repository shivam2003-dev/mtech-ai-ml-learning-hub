# Prerequisites

These are educational prerequisites, not brochure-defined admission rules.

- Python functions, exceptions, virtual environments, NumPy arrays, and tests.
- Classification, precision, recall, calibration, thresholding, and leakage.
- Basic probability, vectors, graphs, and gradient-based optimization.
- TCP/IP, DNS, HTTP, authentication, operating-system processes, and logs.
- Security vocabulary: asset, threat, vulnerability, exploit, control, alert,
  incident, indicator, tactic, technique, and response.

If these ideas are rusty, use the Mathematics, Statistical Methods, Machine
Learning, and Introduction to Parallel and Distributed Programming subjects as
prerequisite routes.
