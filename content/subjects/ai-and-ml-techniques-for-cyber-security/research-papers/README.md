# Research-paper reading path

Start with NIST CSF 2.0, NIST AI RMF 1.0, MITRE ATT&CK, and MITRE ATLAS. Then
read EMBER and DeepLog as primary examples, followed by the two surveys for a
map of applications and open problems. The subject plan will add foundational,
established, modern, survey, and applied readings for each later chapter.
