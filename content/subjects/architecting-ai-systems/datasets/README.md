# Datasets and workloads

- **Synthetic architecture manifests:** fixed-seed JSON fixtures with no
  personal data; publish the generator and SHA-256 hashes.
- **OpenAPI examples:** use the versioned official specification examples and
  preserve their licence.
- **Workload traces:** generate request sizes, rates, and dependency delays
  locally; never replay real identifiers.
- **Systems benchmarks:** use a public release only after checking licence,
  version, hardware assumptions, and redistribution terms.

Every project records source URL, version/date, licence, checksum where possible,
transformation, retention, and deletion policy.
