# Prerequisites

- **Prerequisite:** Python, typing, JSON, HTTP, Git, and basic Linux.
- **Prerequisite:** introductory machine learning, probability, and databases.
- **Supplementary:** containers, distributed systems, cloud networking,
  observability, and IAM.

If a prerequisite is rusty, build the smallest working example first and record
what assumption it tests. Do not treat a copied architecture diagram as
evidence that its assumptions hold.
