# Preface

An AI system is a decision path operated by people, software, data, and
infrastructure. This book connects the official Architecting AI Systems topics
to that path. It keeps model quality, system reliability, agent safety, and
governance in the same design conversation.

The brochure verifies the listed topics and configurable Semester 2–3 placement;
it does not prescribe this chapter order. Proposed tools and implementation
exercises are labelled supplementary or advanced extensions.
