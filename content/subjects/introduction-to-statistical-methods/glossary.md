# Glossary

- **Estimate:** the numerical value produced by an estimator on one dataset.
- **Estimator:** a rule that maps sample data to an estimate.
- **Estimand:** the population quantity an analysis seeks.
- **Observational unit:** the entity counted once for the target analysis.
- **Population:** the collection of units to which a claim refers.
- **Sample:** observed units used by an analysis.
- **Sampling frame:** the operational source from which units could be selected.
- **Selection bias:** systematic mismatch between an estimator's repeated-sampling target under the actual selection process and the intended estimand.
- **Variable:** a documented measurement rule and its recorded value, not merely a column label.
