# How to Use This Book

For each worked problem:

1. state the decision or scientific question;
2. name the population, observational unit, sample, variables, and estimand;
3. draw the route by which observations entered the dataset;
4. identify assumptions and plausible failure modes;
5. calculate a small example by hand;
6. reproduce it in tested Python;
7. report uncertainty and limitations in plain language.

Code demonstrates an implementation under a contract. It does not establish
that a sample represents its population or that an association is causal.
