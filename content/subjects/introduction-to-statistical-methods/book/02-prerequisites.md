# Prerequisites

These are proposed educational prerequisites, not official university
requirements:

- algebra, functions, logarithms, and summations;
- basic Python functions, collections, exceptions, and tests;
- rows, variables, units, missing values, and simple plots;
- probability, random-variable, expectation, and variance notation from
  Mathematical Foundations for Machine Learning.

Chapter 1 uses expectation only in a clearly marked supplementary derivation.
It does not redevelop probability axioms or distribution theory.
