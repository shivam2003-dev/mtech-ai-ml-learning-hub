# Machine Learning

> **Curriculum status:** the programme brochure explicitly lists Machine
> Learning as a Semester 1 compulsory subject and provides a prose topic list.
> The twelve-chapter grouping is an educational interpretation of that list,
> not an invented university unit structure. Additions are labelled
> **Prerequisite**, **Supplementary**, **Advanced extension**, or **Industry
> application**.

Machine learning is the disciplined construction of systems whose behaviour
improves through data or experience. This book begins with the decision and
evidence contract, then develops Bayesian learning, linear and non-linear
models, trees and minimum description length, instance-based methods, support
vector machines, ensembles, clustering, Gaussian mixture models, and model
comparison.

## Available reference chapter

1. [Learning Problems and the ML Workflow](./chapters/01-learning-problems-and-the-ml-workflow/) — **Official topics with labelled supplementary and industry depth**. A running maintenance story, formal empirical-risk baseline, tested NumPy and scikit-learn implementations, leakage analysis, evaluation contract, and study lab.
