# Mathematical notation

- Scalars use italic lowercase letters such as $y$.
- Vectors use bold lowercase letters such as $\mathbf{x}\in\mathbb{R}^d$.
- Matrices use bold uppercase letters such as $\mathbf{X}\in\mathbb{R}^{n\times d}$.
- A dataset is $\mathcal{D}=\{(\mathbf{x}_i,y_i)\}_{i=1}^{n}$.
- A learned prediction rule is $h:\mathcal{X}\rightarrow\mathcal{Y}$.
- A loss is $\ell(h(\mathbf{x}),y)$; empirical risk is its sample average.
- A hat marks a quantity estimated from data, such as $\hat R$.

Every chapter defines any additional notation before use.
