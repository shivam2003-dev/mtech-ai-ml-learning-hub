# How to use this book

Start with the readiness checklist rather than skipping directly to a large
architecture. For every chapter, keep a shape ledger, symbol table, claim
ledger, and experiment log.

Read the one-minute version first. Reproduce the worked numerical case without
code, then run the published implementation in a pinned environment. Change one
assumption at a time and predict the effect before execution. Complete the
study lab and answer oral questions aloud; fluency requires explaining why a
result holds, not only obtaining it.

Paper reading is layered. Begin with the chapter's question, inspect the primary
source's problem and evidence, separate the paper's claims from later
interpretation, and record what was reproduced locally. Never infer production
safety from a benchmark. Use the related-subject links when a proof, statistical
method, application domain, or systems topic belongs elsewhere.
