# Preface

This book treats a neural network as a mathematical program, an empirical
model, and a component in a larger decision system. Those views must remain
connected. Equations without executable checks can hide orientation errors;
code without derivation can hide accidental behavior; benchmark results
without a task and population can hide invalid claims.

The official brochure provides twelve topic phrases. It does not prescribe this
book's units, prerequisites, chapter order, tools, or workload. Each chapter
therefore marks official coverage and separately labels prerequisite,
supplementary, advanced-extension, and industry-application material.

The writing path is intuition, small example, formal model, derivation,
implementation, evaluation, limitations, and research connection. A chapter is
not approved merely because it is long or executable. Its claims, mathematics,
code, metadata, links, accessibility, and rendered presentation require
independent evidence.
