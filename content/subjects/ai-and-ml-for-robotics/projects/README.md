# Project ladder

The six proposed projects are educational contracts, not official assessment:

1. **Beginner:** differential-drive simulator with a tested proportional controller; deliver a trajectory plot and error analysis.
2. **Beginner:** sensor-noise notebook comparing moving-average and Kalman-style state estimates on synthetic motion.
3. **Intermediate:** imitation-learning policy for a small Gymnasium navigation task; report demonstrations, split protocol, and failure cases.
4. **Intermediate:** perception-to-action experiment with domain randomization; compare held-out visual conditions.
5. **Advanced:** model-predictive controller with a learned dynamics residual; include safety constraints and ablations.
6. **Research:** reproduce one robot-learning paper in simulation, document deviations, and test at least one robustness hypothesis.

Every project needs a problem statement, prerequisites, architecture, dataset or
simulator licence, milestones, metrics, tests, deliverables, extension ideas,
deployment guidance, ethics note, and marking rubric before publication.
