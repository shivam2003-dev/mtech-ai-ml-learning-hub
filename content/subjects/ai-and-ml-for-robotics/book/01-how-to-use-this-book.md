# How to use this book

Read the narrative chapters with a notebook open. First predict what a sensor,
state estimate, policy, or controller should do. Then run the smallest example,
record the assumptions, and change one assumption at a time. Keep a log of
random seeds, software versions, robot morphology, and evaluation episodes.

The words *official*, *prerequisite*, *supplementary*, *advanced extension*, and
*industry application* are evidence labels, not decorative headings. Papers
are reading companions rather than proof that the brochure contains a topic.
