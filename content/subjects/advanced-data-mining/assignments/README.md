# Assignments

1. **Mining contract:** define a unit, availability boundary, pattern family,
   threshold, and permitted action for an authorised dataset.
2. **Metric audit:** reproduce support, confidence, and lift by hand and with
   tested functions; explain a high-confidence, low-lift rule.
3. **Stability memo:** resample a synthetic fixture and report which patterns
   survive a changed week or a removed heavy session.
4. **Representation proposal:** explain whether a later problem needs an
   itemset, sequence, graph, stream, spatial, temporal, or social representation.

Every submission must include provenance, tests, reproducibility instructions,
limitations, and a privacy review. Solutions should be argued in prose rather
than judged by a single score.
