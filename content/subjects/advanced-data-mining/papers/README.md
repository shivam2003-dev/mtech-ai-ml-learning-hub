# Paper reading path

Read in this order: Agrawal et al. (association rules), Han et al. (pattern
growth), Aggarwal (textbook chapters), then a recent survey or systems paper
for the representation you choose. For every paper, record the exact problem,
unit of analysis, candidate search, evaluation split, limitations, and whether
the released data and code can be reproduced. Do not treat citation count as a
quality guarantee.
