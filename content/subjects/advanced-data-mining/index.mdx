# Advanced Data Mining

> **Curriculum status:** the official brochure names Advanced Data Mining as a
> configurable elective and gives a course-topic description, but does not
> assign it to one fixed semester or prescribe chapters. The sequence below is
> an educational interpretation. Prerequisites, examples, tools, workload,
> and assessments are labelled educational design rather than university
> requirements.

The brochure's verified topic phrases are: foundations of data mining and
record data mining; association analysis and pattern discovery; topics beyond
conventional record data mining; mining complex data structures; tree and graph
mining; sequence mining; web and text data mining; stream data mining;
spatiotemporal data mining; multivariate time-series mining; high-dimensional
data clustering; mining social networking sites; multi-relational data mining;
privacy-preserving data mining; and distributed computing solutions for
data-intensive data mining.

## Published reference chapter

1. [From a Table to a Pattern That Can Be Trusted](./chapters/01-from-a-table-to-a-pattern-that-can-be-trusted/) — **Official topic: Foundations of Data Mining and Record Data Mining**, with labelled prerequisite, supplementary, and industry-application depth.

## Proposed book sequence

1. From a Table to a Pattern That Can Be Trusted
2. Association Analysis and Pattern Discovery
3. Beyond Conventional Records: Complex Data Objects
4. Trees, Graphs, and Structural Patterns
5. Sequences, Episodes, and Ordered Behaviour
6. Web and Text Data Mining
7. Streams, Windows, and Changing Distributions
8. Spatiotemporal Data Mining
9. Multivariate Time-Series Mining
10. High-Dimensional Data Clustering
11. Mining Social Networking Sites Responsibly
12. Multi-Relational Data Mining
13. Privacy-Preserving Data Mining
14. Distributed Computing for Data-Intensive Mining
15. From Discovered Pattern to Reproducible Decision

Only Chapter 1 is available as an independently approved reference chapter. Later
chapters remain plans until their evidence, code, mathematical, editorial,
originality, accessibility, and rendered-site gates pass.
