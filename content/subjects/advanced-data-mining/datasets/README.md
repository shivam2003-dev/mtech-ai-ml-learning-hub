# Datasets

The chapter uses a tiny synthetic basket fixture embedded in the MDX. It is
safe to reproduce and contains no personal data. For further work, generate
controlled multi-regime baskets with a fixed seed or use a dataset whose terms
explicitly permit mining and redistribution. Record title, creator,
publication year, URL, licence, access date, schema, checksum, known bias,
preprocessing, and deletion contact. Do not download or publish private event
logs, social-network identities, or proprietary web crawls without approval.
